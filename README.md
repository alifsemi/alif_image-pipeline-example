# Image Pipeline Project User Guide  
The image pipeline application demonstrates a complete workflow from camera sensor capturing to image storage. The user can find the source code of this project from the `image_pipeline` folder, and a detailed user guide under the `doc` folder: [Image_Pipeline_Project_User_Guide](doc/Image_Pipeline_Project_User_Guide.md).    
>Note: Please use E4 or E8 device to run the demo applications, since the image signal processor (ISP) and the JPEG encoder are only available on these two SoCs.  

>Note: The applications in this project is tested on DevKit-E8 and AppKit-E8, with a serial MT9M114 camera and a ILI9806E LCD display. When mounting the camera, please use the connector on the opposite side to the processor.
